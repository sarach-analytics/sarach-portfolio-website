How it worksเรียนยังไง

No videos. You give plain-language lessons to an AI coding assistant (Claude Code or Cursor). It writes the agent for your data while you steer and check every step. You keep the finished agent, five sample businesses, and a single-seat commercial licence.ไม่มีวิดีโอ คุณส่งบทเรียนภาษาธรรมดาให้ AI ผู้ช่วยเขียนโค้ด (Claude Code หรือ Cursor) มันจะเขียน agent สำหรับข้อมูลของคุณ ส่วนคุณเป็นคนกำหนดทิศทางและตรวจทุกขั้น ได้ agent ที่เสร็จแล้ว ธุรกิจตัวอย่าง 5 แบบ และไลเซนส์เชิงพาณิชย์สำหรับ 1 คน

What it is notสิ่งที่คอร์สนี้ไม่มี

Not a platform. No vector database, no multi-agent setup, no data-engineering pipeline, no hosting. It runs on your machine. Your spreadsheet needs to be analysis-ready; if it isn't, that's a separate step or a done-for-you job.ไม่ใช่แพลตฟอร์ม ไม่มี vector database ไม่มีระบบหลาย agent ไม่มี data pipeline และไม่มีโฮสติ้ง รันบนเครื่องคุณ spreadsheet ต้องพร้อมวิเคราะห์ ถ้ายังไม่พร้อม นั่นเป็นอีกขั้นหนึ่ง หรือให้ผมทำให้ได้
