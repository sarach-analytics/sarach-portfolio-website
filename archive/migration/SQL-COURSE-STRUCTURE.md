## 🎯 **Learning Outcomes**

### **After BASIC I, students will be able to:**
- ✅ Understand database fundamentals and relational concepts
- ✅ Write SELECT queries to retrieve data
- ✅ Filter data using WHERE and comparison operators
- ✅ Use pattern matching (LIKE), ranges (BETWEEN), and handle NULL values
- ✅ Sort and limit query results
- ✅ Manipulate strings using SQL functions

### **After BASIC II, students will be able to:**
- ✅ Combine multiple conditions using logical operators
- ✅ Join multiple tables using INNER, LEFT, and RIGHT JOINs
- ✅ Use aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- ✅ Group data using GROUP BY
- ✅ Work with dates and times in SQL
- ✅ Write complex queries combining multiple concepts
